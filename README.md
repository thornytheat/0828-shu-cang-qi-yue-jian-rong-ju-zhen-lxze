# 数仓契约兼容矩阵

数据平台发版工程师可在工作台上传来源 CSV，对照规则判断差异，签发合格批次或记录暂缓意见。

按字段稳定编号核对读写版本，检查精度变化、默认值和可空性。

工作台另提供“表级独立签发”：逐表核对候选写版本与所有在用读版本；任一在用读版本不兼容则整表暂缓。读版本在核对后退役或恢复会使原结论失效，必须重新核对。不同批次并发提交同表的两个候选写版本时只有一个生效，批次内其他已兼容表仍可独立签发。接口见 [阶段接口](docs/HTTP.md)。

## 启动

```sh
docker compose up --build -d --wait
```

打开 <http://localhost:18327>。页面预览带异常样例。选中阶段查看计算证据，选择可签发样例并执行批次，然后提交复核意见。

## 核验

```sh
docker compose exec -T app pytest -q
```
